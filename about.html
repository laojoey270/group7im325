About Mini YouTube App

Project Description

Mini YouTube App is a simple web application inspired by YouTube. This project allows users to search videos using the YouTube API and display video results directly on the webpage.

The project was created for educational purposes and to practice HTML, CSS, and JavaScript programming skills.

Features

  • Search YouTube videos
  • Display video thumbnails
  • Open videos in YouTube
  • Simple and user-friendly design
